# cayenne-price-analysis

Automobile depreciation is something that affects nearly all cars, unless it's a Ferrari or something. 

This holds true for the Porsche Cayenne, which I was lucky enough to have as my first car. Even though Porsche is a luxury brand, the depreciation of the Cayenne is especially apparent, having prices drop as low as nearly $5000 in the current market.
This project is supposed to take info from various websites, such as FaceBook Marketplace, eBay Motors, Cars and Bids, as well as AutoTempest in order to track prices of the Cayenne (and eventually other vehicles) and predict what it will be at in the future.
